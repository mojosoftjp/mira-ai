Windows で声でパソコンを操作する方法

音声アクセス・音声入力・Copilot・Mira の違い ｜ 2026 年 10 月 14 日 ｜ Mojosoft

「声でパソコンを操作したい」といっても、やりたいことによって向いている方法が違います。Windows には無料の標準機能があるので、まずはそちらを試すのがおすすめです。

この記事では、Windows 11 の標準機能（音声アクセス・音声入力）、Microsoft の Copilot、そして無料の AI 音声アシスタント Mira を、できること・日本語対応・インターネットの要否・費用で比べます。内容は 2026 年 10 月時点の Microsoft の公式情報に基づいています（出典は記事の最後）。

※ Mira は、この記事を書いている Mojosoft が開発しているアプリです。

音声アクセス（Windows 11 の標準機能）

声で Windows 全体を操作するための、Windows 11 の標準機能です。アクセシビリティ（障がいのある方などの使いやすさ）のための機能として作られていますが、誰でも使えます。

できること

  • アプリを開く・切り替える
  • 画面の項目を名前で指定してクリックする。番号を表示して番号でクリックする、画面を格子で区切って位置を指定する、といった方法もあります
  • スクロール、右クリック、ウィンドウの最大化や画面の端への配置
  • 声で文字を入力する（ディクテーション）

使える言い回しは、Microsoft の音声アクセスのコマンド一覧にまとまっています。

日本語への対応

2025 年 10 月の Windows 11（24H2 / 25H2）向けの更新から、日本語に対応しました。少しずつ配布される方式のため、使えるようになる時期は PC によって異なります。

インターネットは必要？

音声の認識は PC の中で行うため、インターネットに接続していなくても使えます。ただし、最初の設定のときだけ、認識用の言語ファイルをダウンロードするためにインターネット接続が必要です。

始め方

  1. [スタート] ＞ [設定] ＞ [アクセシビリティ] ＞ [音声認識] を開く
  2. 「音声アクセス」をオンにする（画面の案内に沿って初期設定をする）
  3. サインインのあとに自動で始める設定もあります。Alt + Shift + B で聞き取りとスリープを切り替えられます。スリープ中に「音声アクセスのウェイク アップ」と言っても、聞き取りに戻ります

以前の「Windows 音声認識」は、Windows 11（22H2 以降）では 2024 年 9 月に音声アクセスへ置き換えられました。

音声入力（Win + H）

キーボードの代わりに、声で文字を入力する機能です。Windows 11 で使え、日本語にも対応しています。Windows 10 にも Win + H のディクテーションがありますが、Microsoft が案内する対応言語に日本語は含まれていません。Windows 10 で日本語を声で入力するには、以前からある Windows 音声認識を使います。

  1. 文字を入力したい欄にカーソルを置く
  2. Win + H を押して話す
  3. 止めるときは「聞き取りを停止する」と言うか、マイクのボタンを押す

音声入力は Microsoft のクラウド（Azure の音声サービス）で認識するため、インターネット接続が必要です。文字の入力に特化しているので、アプリの操作には音声アクセスを使います。

声で文字を入力する方法（音声アクセス・Word のディクテーション・オフラインの専用ソフトを含む）は、別の記事「Windows で音声入力する方法」でくわしく比べています。

Copilot（Microsoft）

Microsoft の AI アシスタントです。Copilot キーか Win + C で開き、声で会話できます。日本語で会話でき、Windows のアプリでは Microsoft アカウントでのサインインが必要です。

「Hey Copilot」で呼び出す

  • Copilot アプリの設定で「"Hey Copilot" を聞く」をオンにすると、声で呼び出せます（初期設定はオフ）
  • 呼びかけは英語の "Hey Copilot" だけに反応します。呼び出したあとの会話は日本語でできます
  • 呼びかけの検出は PC の中で行い、答えるにはインターネット接続が必要です。Copilot アプリが起動している必要があります

パソコンの操作

通常の Copilot は、アプリの起動やクリックを代わりに行うものではありません。Windows の設定については、該当する設定ページへ案内します。画面を見せて相談できる「Copilot Vision」も、画面の一部を示すことはあっても、クリック・入力・スクロールはしません。

Copilot が PC の作業を代わりに行う機能（Copilot Actions）は、2026 年 10 月時点では Windows Insider 向けの試験的な機能です。Copilot+ PC 向けの同様の機能も、今後提供されると発表されています。

費用

Copilot には無料で使える範囲と、Microsoft 365 のサブスクリプションで広がる範囲があります。2026 年 10 月時点では、声での会話や Copilot Vision が無料で使えるかについて、Microsoft の公式ページどうしで記述が分かれています（無料の個人アカウントで音声を使えるとするページと、対象のサブスクリプションが必要とするページがあります）。使う前に、Microsoft の最新の案内をご確認ください。

Mira（無料の AI 音声アシスタント）

Mira は、名前を呼んで AI と話すための Windows 用アプリです。「ミラお願い」（好きな言葉に変更できます）と呼びかけると聞き取りを始め、答えを声で返します。

できること

  • AI との会話（Gemini・OpenAI・Claude のほか、Ollama・LM Studio・Lemonade のローカル LLM から選べます）
  • 今日から 7 日間の天気予報
  • 登録したキーワードでアプリやサイトを開く（音声ランチャー）、登録したサイトの内容を要約して読み上げる（Web ウォッチ）
  • アラーム・タイマー・スケジュール、音量の調整、クリップボードの読み書き
  • 「画面を見て」と頼むと、画面の内容を AI が説明（画面認識。クラウドの AI を使います）
  • AivisSpeech や VOICEVOX を入れると、好きなキャラクターの声で答えます
  • ライブモード（Google の Gemini Live を使ったリアルタイムの会話。初期設定はオフ）

できないこと

Mira はクリック・スクロール・ウィンドウの操作はできません。ただし、ライブモードでは AI がキー操作や文字入力を行えるため、ショートカットキーでウィンドウを閉じたり切り替えたり、ページを送ったりすることがあります（不要なら、設定画面の「Live」タブで「PC操作（Function Calling）」をオフにできます）。Windows 全体を声で操作したいときは、音声アクセスが向いています。

必要なもの・費用

  • Windows 10（64 ビット・バージョン 2004 以降）または Windows 11、マイク
  • Mira 自体は無料です（機能の制限・試用期間・サブスクリプションはありません）
  • クラウドの AI を使う場合は、ご自身の API キーが必要です。初期設定の Gemini のキーは Google AI Studio で無料で取得でき、無料枠の範囲なら料金はかかりません。ただし無料枠では、送った内容が Google の製品改善に使われることがあります（有料枠では使われません）
  • ローカル LLM なら API キーは要りません。Ollama・LM Studio・Lemonade のいずれかを別にインストールし、モデルを入れておきます
  • 最初のセットアップで、音声認識のモデル（約 460MB）をダウンロードします。このときはインターネット接続が必要です

始め方

  1. Microsoft Store か ダウンロードページから入手する
  2. 最初に表示されるセットアップで、Gemini の API キーを入力する（ローカル LLM を使う場合は設定画面の AI タブで選ぶ）
  3. 「ミラお願い、明日の天気を教えて」のように話しかける

使い方の詳細は Mira のヘルプをご覧ください。

声やデータはどこで処理されるか

  • 音声アクセス — 音声の認識は PC の中で行います
  • 音声入力 — Microsoft のクラウド（Azure の音声サービス）で認識します
  • Copilot — "Hey Copilot" の検出は PC の中、会話は Microsoft のクラウドで処理します
  • Mira — 呼びかけの検出と音声認識は PC の中で行います。ただし、ライブモード（初期設定はオフ）では、マイクの音声を Google の Gemini Live に送ります。会話は選んだ AI に送ります。ローカル LLM を選び、読み上げに AivisSpeech・VOICEVOX か Windows 標準の音声を使えば、会話は PC の中で完結します（クラウドの API キーを保存しているか環境変数に設定していると、Mira の起動時や設定の保存時にローカルの AI が起動していなければクラウドの AI に切り替わり、再起動か設定の保存までそのままです）。天気・検索・画面認識などで外部に送るものは、データの流れにまとめています

よくある質問

Q. 無料で、声でパソコンを操作できますか？

できます。Windows 11 の音声アクセスと音声入力は、Windows の標準機能なので追加の費用はかかりません。

Q. Windows 10 では使えますか？

音声アクセスは Windows 11 の機能です。Windows 10 の Win + H（ディクテーション）は日本語に対応していないため、日本語を声で入力するには、以前からある Windows 音声認識を使います。Mira も Windows 10（64 ビット）で使えます。なお、Windows 10 のサポートは 2025 年 10 月 14 日に終了しています。

Q. Cortana はもう使えませんか？

Windows の Cortana アプリは 2023 年春に廃止されました。声で呼びかけて質問する使い方は、Copilot や Mira で代わりにできます。

Q. Mira は Windows の操作をすべて声でできますか？

できません。Mira が得意なのは、AI との会話と、天気・アプリの起動・アラームなどの決まった操作です。クリックやスクロールまで声でしたい場合は、音声アクセスを使ってください。

プライバシーポリシー

最終更新: 2026年10月13日

はじめに

Mira（ミラ）は Mojosoft が開発する Windows デスクトップ AI 音声アシスタントです。本ポリシーでは、Mira がどのようにデータを取り扱うかを説明します。

データ収集について

Mira はユーザーの個人情報を収集・送信しません。すべてのデータはお使いの PC のローカルに保存されます。Mojosoft のサーバーに送信されるデータはありません。

ローカル保存データ

Mira は以下のデータをお使いの PC 内 (%LOCALAPPDATA%\Mira\) に保存します:

  • settings.json — アプリの設定（AI プロバイダ、TTS 設定、ウェイクワード等）
  • secrets.dat — API キー（Windows DPAPI で暗号化保存）
  • memory.json — 会話の中で Mira が記憶した情報
  • schedules.json — スケジュール・アラーム
  • diag.log — 診断ログ（自動ローテーション）

AI プロバイダへのデータ送信

Mira でクラウド AI プロバイダ（Gemini、OpenAI、Anthropic 等）を使用する場合、音声認識後のテキストと、AI が答えるために使う情報（Mira が覚えた記憶・予定・おぼえがき、ツールの結果（Web 検索の結果や、ライブモードで読み取ったクリップボードの文字など））が、選択したプロバイダの API に送信されます。各プロバイダのプライバシーポリシーが適用されます。

Gemini API を無料枠で使う場合のご注意: Google の料金ページによると、無料枠では送信した内容（会話のテキスト、AI に渡す記憶・予定・おぼえがき、ツールの結果（クリップボードの文字など）、画面認識のスクリーンショット、Gemini Live の音声と画面キャプチャなど）が Google の製品改善に使われることがあります。課金を有効にしたプロジェクト（有料枠）の API キーでは使われません。最新の扱いは Gemini API の料金ページをご確認ください。

ローカル AI（Ollama、LM Studio、Lemonade）を使用する場合、データは一切外部に送信されません。

Screen Vision（画面認識）

画面認識（Screen Vision）を使用する場合、スクリーンショット画像が選択した Vision 対応 AI プロバイダに送信されます。ローカルの Vision 対応モデル（Ollama + llava 等）を使用すれば、外部送信なしで利用できます（ただし、Gemini Live モード中の画面キャプチャは、この設定にかかわらず Google に送信されます。下記参照）。

Gemini Live モード

Gemini Live モードでは、音声データがリアルタイムで Google のサーバーにストリーミング送信されます。Google の利用規約およびプライバシーポリシーが適用されます。Live モードは初期設定では無効です。設定で有効にすると、ウェイクフレーズ（初期設定「ミラライブ」）を検出したときに始まり、停止フレーズで終わります。周りの音をウェイクフレーズと誤って検出して始まることがあるため、v2.3.1 からは通常の呼びかけより高い精度で検出したときだけ起動するようにしています。Live を使わない場合は、無効のままにしておくことをおすすめします。

ライブモードの「画面キャプチャ」を有効にしているときは、AI が画面を確認すると、そのスクリーンショットも Google に送信されます（v2.3.1 から、新しくインストールした場合の初期設定は無効です。それ以前から使っている場合は、以前の設定のままです）。v2.3.1 からは、ユーザーに頼まれたときだけ画面を確認するよう AI に指示していますが、AI の判断によるため、頼んでいないのに確認することが完全になくなるとは限りません。画面を送りたくない場合は、設定のライブモードのタブで「画面キャプチャ」を無効にしてください。

マイクの使用

Mira はウェイクワード検出のためにマイク入力を常時監視しますが、録音データは保存も送信もされません（Gemini Live モード中を除きます。上記参照）。音声認識（STT）は PC 上のローカル Whisper モデルで処理され、認識後の音声データは破棄されます。

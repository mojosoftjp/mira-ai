プライバシーポリシー Privacy Policy

最終更新: 2026年10月13日 Last updated: October 13, 2026

はじめに Introduction

Mira（ミラ）は Mojosoft が開発する Windows デスクトップ AI 音声アシスタントです。本ポリシーでは、Mira がどのようにデータを取り扱うかを説明します。 Mira is a Windows desktop AI voice assistant developed by Mojosoft. This policy explains how Mira handles your data.

データ収集について Data Collection

Mira はユーザーの個人情報を収集・送信しません。すべてのデータはお使いの PC のローカルに保存されます。Mojosoft のサーバーに送信されるデータはありません。 Mira does not collect or transmit your personal information. All data is stored locally on your PC. No data is sent to Mojosoft's servers.

ローカル保存データ Locally Stored Data

Mira は以下のデータをお使いの PC 内 (%LOCALAPPDATA%\Mira\) に保存します: Mira stores the following data locally on your PC (%LOCALAPPDATA%\Mira\):

  • settings.json — アプリの設定（AI プロバイダ、TTS 設定、ウェイクワード等）settings.json — App settings (AI provider, TTS, wake word, etc.)
  • secrets.dat — API キー（Windows DPAPI で暗号化保存）secrets.dat — API keys (encrypted with Windows DPAPI)
  • memory.json — 会話の中で Mira が記憶した情報memory.json — Information Mira remembers from conversations
  • schedules.json — スケジュール・アラームschedules.json — Schedules and alarms
  • diag.log — 診断ログ（自動ローテーション）diag.log — Diagnostic logs (auto-rotated)

AI プロバイダへのデータ送信 Data Sent to AI Providers

Mira でクラウド AI プロバイダ（Gemini、OpenAI、Anthropic 等）を使用する場合、音声認識後のテキストと、AI が答えるために使う情報（Mira が覚えた記憶・予定・おぼえがき、ツールの結果（Web 検索の結果や、ライブモードで読み取ったクリップボードの文字など））が、選択したプロバイダの API に送信されます。各プロバイダのプライバシーポリシーが適用されます。 When using cloud AI providers (Gemini, OpenAI, Anthropic, etc.), transcribed text from your voice input, together with what the AI uses to answer (the memory, schedule and notes Mira keeps, and tool results such as web search results or clipboard text read in Live mode), is sent to the selected provider's API. Each provider's privacy policy applies.

Gemini API を無料枠で使う場合のご注意: Google の料金ページによると、無料枠では送信した内容（会話のテキスト、AI に渡す記憶・予定・おぼえがき、ツールの結果（クリップボードの文字など）、画面認識のスクリーンショット、Gemini Live の音声と画面キャプチャなど）が Google の製品改善に使われることがあります。課金を有効にしたプロジェクト（有料枠）の API キーでは使われません。最新の扱いは Gemini API の料金ページをご確認ください。 Note on the Gemini API free tier: According to Google's pricing page, on the free tier the content you send (such as conversation text, the memory, schedule and notes given to the AI, tool results such as clipboard text, Screen Vision screenshots, and Gemini Live audio and screen captures) may be used by Google to improve its products. It is not used when your API key belongs to a project with billing enabled (paid tier). See the Gemini API pricing page for the current terms.

ローカル AI（Ollama、LM Studio、Lemonade）を使用する場合、データは一切外部に送信されません。 When using local AI (Ollama, LM Studio, Lemonade), no data is sent externally.

Screen Vision（画面認識） Screen Vision

画面認識（Screen Vision）を使用する場合、スクリーンショット画像が選択した Vision 対応 AI プロバイダに送信されます。ローカルの Vision 対応モデル（Ollama + llava 等）を使用すれば、外部送信なしで利用できます（ただし、Gemini Live モード中の画面キャプチャは、この設定にかかわらず Google に送信されます。下記参照）。 When using Screen Vision, screenshot images are sent to the selected Vision-capable AI provider. Using a local Vision model (e.g., Ollama + llava) keeps all data on your PC (except for screen captures during Gemini Live mode, which are sent to Google regardless of this setting; see below).

Gemini Live モード Gemini Live Mode

Gemini Live モードでは、音声データがリアルタイムで Google のサーバーにストリーミング送信されます。Google の利用規約およびプライバシーポリシーが適用されます。Live モードは初期設定では無効です。設定で有効にすると、ウェイクフレーズ（初期設定「ミラライブ」）を検出したときに始まり、停止フレーズで終わります。周りの音をウェイクフレーズと誤って検出して始まることがあるため、v2.3.1 からは通常の呼びかけより高い精度で検出したときだけ起動するようにしています。Live を使わない場合は、無効のままにしておくことをおすすめします。 In Gemini Live mode, audio data is streamed in real-time to Google's servers. Google's terms of service and privacy policy apply. Live mode is off by default. When enabled in Settings, it starts when the wake phrase is detected ("Mira live" by default) and ends with a stop phrase. Because surrounding sounds can occasionally be mistaken for the wake phrase, from v2.3.1 Live starts only when the phrase is detected with higher confidence than a regular wake word. If you don't use Live, we recommend leaving it disabled.

ライブモードの「画面キャプチャ」を有効にしているときは、AI が画面を確認すると、そのスクリーンショットも Google に送信されます（v2.3.1 から、新しくインストールした場合の初期設定は無効です。それ以前から使っている場合は、以前の設定のままです）。v2.3.1 からは、ユーザーに頼まれたときだけ画面を確認するよう AI に指示していますが、AI の判断によるため、頼んでいないのに確認することが完全になくなるとは限りません。画面を送りたくない場合は、設定のライブモードのタブで「画面キャプチャ」を無効にしてください。 When Live mode's Screen Capture option is on, any time the AI looks at your screen the screenshot is also sent to Google (from v2.3.1 it is off by default for new installs; if you installed an earlier version, your previous setting is kept). From v2.3.1 the AI is instructed to look at the screen only when you ask, but as this relies on the AI's judgment, it may still occasionally look without being asked. If you don't want your screen sent, turn off Screen Capture in the Live mode tab of Settings.

マイクの使用 Microphone Usage

Mira はウェイクワード検出のためにマイク入力を常時監視しますが、録音データは保存も送信もされません（Gemini Live モード中を除きます。上記参照）。音声認識（STT）は PC 上のローカル Whisper モデルで処理され、認識後の音声データは破棄されます。 Mira monitors microphone input for wake word detection, but audio data is neither saved nor transmitted (except during Gemini Live mode; see above). Speech recognition (STT) is processed by a local Whisper model on your PC, and audio data is discarded after transcription.
